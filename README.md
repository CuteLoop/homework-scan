# Homework Scan

A private, mobile-first PWA that turns homework photos into a compressed, shareable PDF entirely in the browser.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is in `dist/` and can be hosted on any static host.

## Privacy

Photos never leave the device. Resizing, rotation, JPEG compression, and PDF generation all happen locally in the browser.
